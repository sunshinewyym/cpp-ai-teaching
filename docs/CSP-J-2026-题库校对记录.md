## 系统接入

- 数据文件：`web/src/data/csp2026.js`，包含 15 道选择题、3 道阅读程序题、2 道完善程序题，共 43 小题。
- CSP-J/S 练习：CSP-J 新增 2026 年，默认进入最新年份。CSP-S 仍保留已有年份，不创建不存在的 2026 题目。
- 整卷测评：提供 `CSP-J-2026`，20 道大题、100 分，分部满分为 30/40/30。
- 作业管理：通过共享题库筛选 CSP-J、2026 年及知识点后选题布置。
- 集训题目查找、学生集训题面与选择题错题本同步认识新增题目；不自动改动已有课程题单。
- 不填写尚未核实的 2026 广州晋级分数线。

## 验证方法

在仓库目录执行：

```powershell
node web/scripts/verify-csp-2026.mjs
node server/routes/cspPapers.test.js
node server/routes/homework.test.js
npm --prefix web run build
```

第一项需要可用的 `g++`（也可设置 `CXX` 指定编译器），会从实际题库提取代码、去除显示行号、填入正确选项后编译运行。覆盖：

- 43 小题答案、唯一编号、选项对应及每题具体解析；
- 代码行数 18/34/25/28/37，以及题目引用的关键行号；
- BFS 入队次序、栈序列、递推、最大公约数、硬币最优枚数、二分查找和中位数；
- 三道阅读程序的输出与删改语句反例；
- 多组源进制 m×n 到 n 进制的结果，与独立大整数计算比对；
- 平衡分割结果，与独立枚举所有非空切分集合比对（包含字符 9、A～F、小数平均值、全零和 20 字符输入）；
- 整卷布置、学生提交、开放解析前隐藏分数、开放后显示 30/40/30 分部满分与正确得分。

接口测试使用临时数据库，不读写现有学生的提交记录。上线时需要一并重新构建前端、更新后端题库并重启后端；只替换前端会导致整卷目录与判分仍使用旧数据。
